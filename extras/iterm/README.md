# winteriscoming for iTerm2

[winteriscoming.nvim](../../README.md) theme for [iTerm2](https://iterm2.com), generated from the same palettes as the Neovim colorscheme.

Every file comes in all three styles (`winteriscoming_blue`, `winteriscoming_black`, `winteriscoming_light`). The examples use `blue`; swap in the style you want. Replace `curl … -o` with a plain copy if you've cloned the repo.

## Install

```sh
curl -fsSL -o ~/Downloads/winteriscoming_blue.itermcolors \
  https://raw.githubusercontent.com/bytebeast/winteriscoming.nvim/main/extras/iterm/winteriscoming_blue.itermcolors
```

In iTerm2, open **Settings → Profiles → Colors**, click **Color Presets… → Import…**, choose the file, then pick **winteriscoming_blue** from the same menu.
