forecast.luainit.lua 
-- winter is coming
local M = {}

---@param city string
---@param days? number
function M.forecast(city, days)
  local report = { city = city, days = days or 7, snow = true }
  if not report.city:match("^%a+$") then
    error(("unknown city: %s"):format(city))
  end
  vim.notify("forecasting " .. city, vim.log.levels.INFO)
  return setmetatable(report, { __index = M })
end

return M

-- why winteriscoming

The theme you know, at home in a terminal

  • The real palette. Every color comes from John Papa's theme. faithful = true brings back the exact VS Code values.
  • Tuned for a terminal. Where VS Code leaned on italics to tell blues apart, functions, variables and constants are nudged apart instead.
  • VS Code's details. Declared fields and accessed properties look different, and library globals get the library teal.
  • Built for color blindness. Red-green and blue-yellow modes remap diffs, git signs and diagnostics, picked by simulating each deficiency.
  • High contrast on demand. One option lifts every syntax color to WCAG AA, plus comments and line numbers.
  • Roles, not hex codes. Change colors.syntax.keyword or the ice it points at, and every language follows.
  • Checked against the real tools. The Helix, Zed, Yazi, k9s, eza, btop and fish themes, among others, are tested against each tool's own list of theme keys.

-- features

Everything you'd expect, and a few things you wouldn't

  • 75+ plugin integrationsAuto-detected from lazy.nvim or vim.pack
  • 26 tool themesTerminals, CLI tools, Vim, Zed, Helix
  • Colorblind modes"red-green" or "blue-yellow"
  • High contrastEvery syntax color at AA, brighter comments and line numbers
  • Subtle commentsFade comments behind code, optionally keep docstrings
  • Saturation and accentMute the colors, keep the contrast, pick an accent
  • Transparent and borderlessFor terminal blur and shade-framed pickers
  • Rainbow variablesA color per local variable, JetBrains-style
  • Two hookson_colors and on_highlights
  • Lualine themesOne per style, plus one that follows yours
  • :checkhealthWarns when your overrides hurt contrast
  • Tested on stable and nightlyCI on every push

-- try it

Bundle up

A true-color terminal and a recent Neovim. Every option is in the README.

-- ~/.config/nvim/lua/plugins/winteriscoming.lua
return {
  { "bytebeast/winteriscoming.nvim", lazy = false, priority = 1000, opts = {} },
  { "LazyVim/LazyVim", opts = { colorscheme = "winteriscoming" } },
}
{
  "bytebeast/winteriscoming.nvim",
  lazy = false,
  priority = 1000,
  config = function()
    require("winteriscoming").setup({ style = "blue" })
    vim.cmd.colorscheme("winteriscoming")
  end,
}
-- Neovim 0.12+
vim.pack.add({ "https://github.com/bytebeast/winteriscoming.nvim" })
vim.cmd.colorscheme("winteriscoming-black")
